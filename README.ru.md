# Mangosteen для Windows

Windows-версия [Mangosteen](https://github.com/SpaceCadet0/Mangosteen), приложения для строки меню macOS, которое конвертирует и редактирует файлы через колесо. Зажмите клавишу-модификатор, щёлкните правой кнопкой по файлу в Проводнике или на рабочем столе и выберите действие на круглом колесе у курсора. Результат появится рядом с оригиналом. Всё работает без интернета.

Это ранняя версия (0.2). У двух репозиториев нет общего кода, у каждого свои релизы и CI.

## Клавиши

| Зажать | Правый щелчок по файлу | Колесо |
| --- | --- | --- |
| Shift | в Проводнике или на рабочем столе | Конвертация |
| Ctrl | в Проводнике или на рабочем столе | Инструменты |
| Alt | в Проводнике или на рабочем столе | Действия |

Правый щелчок без этих клавиш или в любом другом месте открывает обычное контекстное меню.

Сегмент выбирается левым щелчком. Esc или щелчок мимо колеса закрывает его. Открыли не то колесо? Пока оно на экране, нажмите Shift, Ctrl или Alt, и откроется нужное колесо для тех же файлов. Как и в Проводнике, правый щелчок по выделенному файлу берёт всё выделение, а по невыделенному выделяет только этот файл.

Для других приложений есть значок в трее: **Choose files…** открывает диалог выбора файлов, а затем показывает колесо у курсора.

## Что умеет

### Конвертация (Shift)

| Тип | Форматы |
| --- | --- |
| Изображения | PNG, JPG, WebP, TIFF, BMP, GIF, PDF; ещё читает ICO, а WebP, HEIC и AVIF, если установлены кодеки из Microsoft Store |
| PDF | в PNG или JPG (PDF из нескольких страниц превращается в папку со страницами), TXT, Markdown, RTF, DOCX, HTML |
| Документы | DOCX, ODT, RTF, TXT, Markdown, HTML друг в друга и в PDF |
| Субтитры | SRT и VTT друг в друга и в TXT |
| Таблицы | CSV, TSV, XLSX друг в друга (книга с несколькими листами превращается в папку таблиц) |
| Архивы | ZIP, TAR, TAR.GZ друг в друга; папки в архивы |

Результат никогда ничего не перезаписывает: `photo.jpg`, затем `photo 2.jpg`, `photo 3.jpg`. Оригинал не меняется.
Текстовые файлы в старой кириллической кодировке Windows (Windows-1251) читаются правильно. Для долгих задач
появляется небольшая панель прогресса с кнопкой Stop; щелчок по итоговому уведомлению показывает результат в Проводнике.

Пока нет в Windows-версии: вывод в HEIC и AVIF, анимированный WebP, видео и аудио (появятся вместе с ffmpeg) и старый
двоичный формат `.doc`. В документах сохраняются заголовки, абзацы, списки, жирный, курсив, подчёркивание, ссылки и
код; картинки и таблицы внутри документов не переносятся.

### Инструменты (Ctrl)

- **Extract** распаковывает архив в папку рядом с ним.
- **PDF from images**: один PDF, по странице на изображение.
- **Merge** склеивает несколько PDF в один.

Остальные инструменты (сжатие, обрезка, редактор, пометки и другие) показаны серыми и появятся в следующих версиях.

### Действия (Alt)

- **Float** кладёт файлы на плавающую полку. Потом их можно перетащить с полки в любое приложение. По умолчанию
  перетаскивание копирует; переключите полку в Move, чтобы переносить оригиналы. Полка есть и в меню значка.
- **Copy** кладёт сами файлы в буфер обмена: их можно вставить в папку или в сообщение.
- **Move** спрашивает папку и переносит туда файлы.
- **Path** копирует полные пути.
- **Terminal** открывает папку в Windows Terminal (или PowerShell).

## Скачать

Установщика пока нет. Каждый пуш собирает самодостаточный `Mangosteen.exe` (Windows 10 и 11, x64, ставить .NET не нужно):

1. Откройте [вкладку Actions](https://github.com/SpaceCadet0/Mangosteen-Windows/actions/workflows/build.yml) и выберите последний зелёный запуск.
2. В разделе **Artifacts** скачайте **Mangosteen-win-x64** (нужно войти в GitHub) и распакуйте архив.
3. Запустите `Mangosteen.exe`. Сборка не подписана, поэтому SmartScreen может предупредить: нажмите **Подробнее**, затем **Выполнить в любом случае**.

Mangosteen живёт в области уведомлений (если значка не видно, нажмите стрелку рядом с часами). Выйти можно из меню значка.

## Если что-то не работает

Mangosteen пишет журнал в `%LOCALAPPDATA%\Mangosteen\mangosteen.log` (**Open log** в меню значка). В нём записан каждый правый щелчок, который обработал Mangosteen: окно под курсором, выделенные файлы и время. Приложите его к сообщению о проблеме.

## Сборка

Нужен .NET 8 SDK. Приложение для Windows, но компилируется и на macOS и Linux (`EnableWindowsTargeting`):

```
dotnet build Mangosteen.sln
dotnet test tests/Mangosteen.Core.Tests
dotnet publish src/Mangosteen/Mangosteen.csproj -c Release -r win-x64 -o publish
```

Тесты конвертации изображений (`tests/Mangosteen.Windows.Tests`) требуют Windows и запускаются в CI.
