**Download `Mangosteen-win-x64.zip` below** (about 250 MB, Windows 10 and 11, x64), unzip it and run `Mangosteen.exe`.
The build is not signed, so SmartScreen may ask: **More info**, then **Run anyway**.

### New

- **Check for Updates…** in the tray menu and in Settings. It asks GitHub for the latest version and says whether
  yours is the newest; if not, **Download** opens the release page (in the Microsoft Store version, **Open Microsoft
  Store**). It runs only when you click it, and Mangosteen downloads and installs nothing by itself. This is the only
  time the app goes online; the [privacy policy](https://github.com/SpaceCadet0/Mangosteen-Windows/blob/main/PRIVACY.md)
  says so too.

---

- **«Проверить обновления…»** в меню значка и в настройках. Приложение спрашивает у GitHub последнюю версию и говорит,
  самая ли новая у вас; если нет, **«Скачать»** открывает страницу релиза (в версии из Microsoft Store —
  **«Открыть Microsoft Store»**). Проверка идёт только по нажатию, сам Mangosteen ничего не скачивает и не ставит. Это
  единственный случай, когда приложение обращается в интернет; так написано и в политике конфиденциальности.

**Подробнее**, затем **Выполнить в любом случае**.
