The first release of Mangosteen for Windows, the sibling of [Mangosteen for macOS](https://github.com/SpaceCadet0/Mangosteen).

Hold **Shift**, **Ctrl** or **Alt** and right-click a file in File Explorer or on the desktop: a wheel opens at the cursor
with conversions, tools with a live preview, or actions. Results are written next to the original. Everything runs
offline.

**Download `Mangosteen.exe` below** (about 170 MB, Windows 10 and 11, x64) and run it; there is nothing to install. The
build is not signed, so SmartScreen may ask: **More info**, then **Run anyway**.

### What is inside

- Convert images (PNG, JPG, WebP, TIFF, AVIF, BMP, GIF, PDF), PDF, documents (DOCX, ODT, RTF, TXT, Markdown, HTML),
  video, audio, subtitles, tables and archives.
- Tools: Annotate, Background, Editor, Compress, Crop, Collage, Hide faces and text, Metadata, PDF pages and Merge;
  for video and audio Trim, Split, Speed, Volume, Compress, Bleep, Hide on video, Reframe, Join, Frames, Channels and
  Visualizer.
- Actions: Float shelf with thumbnails, Copy, Move, Path, Terminal.
- English, Spanish and Russian.

FFmpeg (GPL v3) is bundled as a separate program; see THIRD-PARTY-NOTICES.md.
