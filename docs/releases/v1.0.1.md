**Download `Mangosteen-win-x64.zip` below** (163 MB, Windows 10 and 11, x64), unzip it and run `Mangosteen.exe`. The
build is not signed, so SmartScreen may ask: **More info**, then **Run anyway**.

### Changes

- **Annotate** opens with the Pencil, which now comes right after Select in the toolbar.
- **Timeline selection** (Trim, Split, Bleep, Hide on video) is framed in yellow, as in the macOS version: bars along
  the top and bottom and a handle at each end, kept inside the selection so they stay visible.
- **Welcome window** redone after the macOS one: the steps, three equal cards for the wheels, a tip, and a
  "Start Mangosteen when I sign in to Windows" check box.

In the background Mangosteen uses no CPU and about 13 MB of private memory (measured in CI).
