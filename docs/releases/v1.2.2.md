**Download `Mangosteen-win-x64.zip` below** (about 250 MB, Windows 10 and 11, x64), unzip it and run `Mangosteen.exe`.
The build is not signed, so SmartScreen may ask: **More info**, then **Run anyway**.

### Fixed

- **Crop**: turning or mirroring a small photo (up to 1600 px) did nothing and wrote an error to the log. It works now.

### Also in this build

- The Microsoft Store package (MSIX) is built with every release: there the Explorer menu sits in Windows 11's main
  right-click menu, and "Start with Windows" is a regular startup task.
- A privacy policy: nothing is collected or sent ([PRIVACY.md](https://github.com/SpaceCadet0/Mangosteen-Windows/blob/main/PRIVACY.md)).
