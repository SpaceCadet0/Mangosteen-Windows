**Download `Mangosteen-win-x64.zip` below** (about 250 MB, Windows 10 and 11, x64), unzip it and run `Mangosteen.exe`.
The build is not signed, so SmartScreen may ask: **More info**, then **Run anyway**.

### Changed

- **Several photos to one PDF**: select two or more photos, hold Shift, right-click and pick PDF — they become one
  "Images.pdf", a page per photo in the order you selected them. Other files in the selection are still converted
  one by one, and a single photo still makes its own PDF. The separate "PDF from images" tool is gone.
- The demo in "How to use Mangosteen" matches the current Convert wheel.

---

- **Несколько фото в один PDF**: выделите два фото или больше, зажмите Shift, щёлкните правой кнопкой и выберите PDF —
  получится один «Images.pdf», по странице на фото в порядке выделения. Остальные файлы выделения конвертируются по
  одному, а одно фото по-прежнему даёт свой PDF. Отдельного инструмента «PDF из фото» больше нет.
- Демо в окне «Как пользоваться Mangosteen» соответствует нынешнему колесу конвертации.
